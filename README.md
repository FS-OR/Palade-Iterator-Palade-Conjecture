# Palade Iterator — Palade Conjecture (Minimal Clinical Tool)

This repository contains the minimal browser-based implementation of the **Palade Iterator**, 
a clinical micro-tool supporting the *Palade Conjecture* within the *Fast Science – Open Research* (FS-OR) ecosystem.

### 🎯 Purpose
A lightweight iterator for simulating and validating clinical patterns related to the 
Palade FH logic framework. Runs fully in-browser, zero dependencies.

### 🔗 Live Demo (GitHub Pages)
https://fs-or.github.io/Palade-Iterator-Palade-Conjecture/

### 📂 Files
- `index.html` — minimal runnable application  
- `LICENSE` — MIT license

### 📘 How to Use
Download or open `index.html` directly in any browser.  
No backend, no installation, no external libraries.
